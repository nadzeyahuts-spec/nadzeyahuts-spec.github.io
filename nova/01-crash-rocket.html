Under the hood

What a production build of this looks like
Randomness

Commit–reveal seed chain: SHA-256(serverSeed : clientSeed : nonce). The hash of every server seed is published before the round; the seed is revealed after. Optional Chainlink VRF for an on-chain entropy source auditors accept.

Round authority

Rounds are server-authoritative. Clients receive a signed round header over WebSocket and interpolate the curve locally — the multiplier you see is a pure function of round start time, so no client can lie about when it cashed out.

Settlement

Batched settlement contract on Base. Stakes escrow on bet, payouts stream on cash-out, ~0.4s finality. Multi-token router auto-swaps USDT / ETH / SOL bridged balances into the house unit.

This prototype

~2.6k lines, single HTML file, zero dependencies. Canvas 2D at 60fps, real SHA-256, deterministic scripted demo track. The production client would run PixiJS + WebGL for particle density.
